1. 用意するもの

機材メモ
MacBook Pro（M1 Max）Intel の Mac でも同じ手順で動きます。
Kinect v1（Xbox 360 用）専用の電源アダプタが必須です。USB だけでは動きません。
プロジェクターHDMI でつなぎます。砂箱の真上か斜め上から投影します。
USB-C の変換アダプタHDMI 用と Kinect 用を別々のポートにつなげるようにしてください（理由は「困ったとき」を参照）。
USB 2.0 ハブ（M1 Mac の場合）M1 Mac では、Kinect を USB 2.0 のハブを通してつなぐと安定します。直接つなぐと映像が届かないことがありました。
砂箱と砂砂の厚さは 10cm 以上あると遊びやすくなります。
平らな板（段ボールなど）キャリブレーションのときに砂箱の上に載せます。

2. Mac へのコピー（インストール）

  1. USB メモリを Mac に挿します。
  2. USB メモリの中にある DuneBox フォルダを、フォルダごとデスクトップにドラッグしてコピーします。
  3. コピーが終わったら USB メモリは外して構いません。

フォルダの中身をバラバラにしないでください。 DuneBox.app は、同じフォルダにある data フォルダを読み込んで動きます。DuneBox.app だけを「アプリケーション」フォルダに移すと起動しません。

デスクトップの DuneBox フォルダの中身はこうなっていれば正しいです。

DuneBox/
├── DuneBox.app        ← アプリ本体
├── data/              ← 画像・設定・キャリブレーション結果
└── はじめにお読みください.html（このファイル）

3. 機材の接続

次の順番でつなぐと確実です。

  1. プロジェクターを Mac につなぐ。
  2. 画面を「拡張」にする。 「システム設定」→「ディスプレイ」を開き、プロジェクターがミラーリングではなく、別の画面（拡張）になっていることを確認します。
  3. Kinect の電源アダプタをコンセントにつなぐ。
  4. Kinect の USB を Mac につなぐ。 プロジェクターとは別の USB-C ポート（または別のアダプタ）につないでください。M1 Mac では USB 2.0 ハブ経由にします。

今回同梱しているキャリブレーション結果は、Kinect から砂の表面まで約 74cm の配置で取ったものです。Kinect・プロジェクター・砂箱の位置を変えていなければ、そのまま使えます。

4. 起動する

はじめて起動するとき

  1. デスクトップの DuneBox フォルダを開きます。
  2. DuneBox.app を右クリック（または control + クリック）して「開く」を選びます。
  3. 「開発元を確認できません」などの確認が出たら、もう一度「開く」を押します。

「開けません」と出て、「開く」ボタンがない場合

「システム設定」→「プライバシーとセキュリティ」を開き、下の方にある DuneBox の「このまま開く」を押してください。2回目からは普通にダブルクリックで起動できます。

起動すると

  • Mac の画面に操作用の画面（右上に「DuneBox 設定」、左下に「状態」パネル）が最大化して出ます。ウィンドウの大きさは自由に変えられ、中央のカメラ映像や地図も合わせて拡大・縮小します。
  • プロジェクターに投影用の画面が全画面で出ます。
  • 左下の「状態」パネルがすべて緑なら準備完了です。Space キーを押すと砂に地形が映ります。
「状態」パネルの表示意味とやること
深度カメラ：接続済み（緑）Kinect がつながっています。
深度カメラ：見つかりません（赤）Kinect の電源と USB を確認してください。「困ったとき」も参照。
砂の範囲・海面の高さ・プロジェクターが「未設定」「未調整」キャリブレーションが必要です。次の章へ。

5. キャリブレーション（必要なときだけ）

Kinect とプロジェクターの位置を合わせる作業です。まず、次のどちらに当てはまるかを確認してください。

A. Kinect・プロジェクター・砂箱の位置を動かしていない場合

「2. プロジェクターを調整」はやらなくて大丈夫です。同梱のキャリブレーション結果がそのまま使えます。

  1. 右上パネルの「1. 砂の範囲を指定」を押す。 Kinect の映像が出るので、砂箱の内側を左上から右下までドラッグします（クリックだけではダメです）。緑の四角が砂箱の内側に収まれば OK です。
  2. Space を押す。 砂に地形が映れば完了です。

B. 位置を動かした場合、または投影が砂とずれている場合

全部で 5〜15 分ほどかかります。

  1. Kinect を 20〜30 分ほど電源を入れたままにしておく。 温まるまで測定が少しずれるためです。
  2. 「1. 砂の範囲を指定」で、砂箱の内側をドラッグする。（A の 1 と同じ）
  3. 砂を平らにならす。 手のひらで軽くなでて、表面をなめらかにします。
  4. 「2. プロジェクターを調整」を押す。 「砂の表面を平らにしてください」と出たら、OK を 1 回だけ押します。
  5. あとは何も触らずに待つ。 砂の上に白黒の市松模様が映り、場所を変えながら自動で 5 回測ります。
  6. 「砂箱を板で覆って OK を押してください」と出たら、平らな板を砂箱の上に載せて OK を押します。また 5 回測ります。
  7. 「キャリブレーション成功」と出たら完了です。 板を外して Space を押してください。

キャリブレーション中は、パネルのボタンを押さないでください。 押せないボタンは灰色になります。途中でやめたいときは「キャリブレーションを中止」を押してください。

「範囲を調整結果に合わせる」は、キャリブレーションが成功した後でだけ使えます。普段は押す必要はありません。

模様がなかなか見つからなくても、そのまま待ってください。 見つからないと模様を少しずつ中央に寄せながら何度もやり直します。1 か所に数分かかることがありますが、止まっているわけではありません。手や体を砂箱の上に入れないでください。部屋を少し暗くすると早く終わります。

10 分以上まったく進まないときは、プロジェクターの光（白い画面や市松模様）が砂に当たっているかを確認してください。

6. 遊び方と操作

砂を手で盛ったり掘ったりすると、高さに合わせて色と等高線が変わります。高いところは茶色、低いところは青（海）になります。

「水」パネル（左側。サンドボックス開始後に出ます）

項目はたらき
水シミュレーション（W）水を流す機能のオン・オフ。
山頂から川を流す（K）いちばん高い山のてっぺんから水がわき出し、低いほうへ流れます。山を作り直すと、約 1 秒後に水源も新しい頂上へ移ります。指で溝を掘ると、水がそこを流れます。
川の水量右に動かすほど水が多く出ます。
手をかざすと雨砂の上に手をかざすと、その下に雨が降ります。
水を消す（X）たまった水をすべて消します。

キーボード操作

キー動作
Spaceサンドボックスを開始
W水シミュレーションのオン・オフ
K山頂から川を流す、のオン・オフ
X水を消す
L溶岩モード
V火山を噴火させる
T色のテーマを切り替え（地形図・海・火山・氷河期・異星）
N昼と夜の切り替え
F魚のゲームを開始
1〜4動物ゲームを難しさ 1〜4 で開始

キー操作は、Mac の画面（操作用ウィンドウ）をクリックしてから行ってください。

7. 終了のしかた（重要）

必ず command + Q か、ウィンドウを閉じて終了してください。

このとき設定が保存されます。「強制終了」や電源を切っての終了では、その回に変えた設定が保存されないことがあります。

8. 困ったとき

症状やること
「深度カメラ：見つかりません」
  1. Kinect の電源アダプタがコンセントに入っているか確認します。
  2. USB を挿し直します。
  3. DuneBox が 2 つ起動していないか確認します（Dock に 2 つ並んでいないか）。2 つあると Kinect を取り合ってつながりません。全部終了してから 1 つだけ起動し直してください。
Kinect を抜き挿ししたらつながらなくなったDuneBox を command + Q で終了し、起動し直してください。
動きがカクカクする／「センサーの更新率」が低いKinect をプロジェクター（HDMI）と同じアダプタにつないでいると遅くなることがあります。別のポートにつなぎ替えてください。ほかの重いアプリも終了してください。
プロジェクターに何も映らないディスプレイ設定が「ミラーリング」になっていないか確認します。DuneBox を起動した後でプロジェクターをつないだ場合は、DuneBox を起動し直してください。
投影された色が砂とずれているキャリブレーションをやり直してください（5章の B）。
「砂の表面を平らにしてください」が何度も出るOK の後にパネルのボタンを押すと、最初からやり直しになります。OK を 1 回押したら、何も触らずに待ってください。
Space を押したらカメラ映像が消えた正常です。開始すると、カメラ映像の代わりに砂の地図が表示されます。地図が小さい・ずれているときは「1. 砂の範囲を指定」からやり直してください。
水が山の上にたまる、変な方向に流れる、砂とずれて映る水の機能はこの版で新しく作り直したもので、Kinect の実機でまだ試していません。X で水を消して、どう見えたかを開発担当に伝えてください（スマホで投影の写真を撮ってもらえると助かります）。
英語の表示にしたいdata/settings/language.txt をテキストエディットで開き、ja を en に書き換えて保存し、起動し直します。

開発担当にログを渡すとき

DuneBox は動作の記録（ログ）を自動で data/DebugFiles/dunebox.log に書き出しています（1 回前の分は dunebox-prev.log）。問題が起きたら、DuneBox を終了してから、この 2 つのファイルを USB メモリなどで渡してください。

設定のバックアップ

キャリブレーション結果は data/settings フォルダに入っています。うまく動いている状態のときに、このフォルダをどこかにコピーしておくと、困ったときに戻せます。

9. このバージョンの注意点

  • M1 Max（Apple Silicon）では、起動と Kinect の接続（USB 2.0 ハブ経由）を確認しています。キャリブレーションの成功はまだ確認できていません。
  • 水の機能（山頂から川、水の向きと位置の修正）は、Kinect の実機ではまだ試していません。
  • うまくいかなかったときは、何をしたときに、画面に何が出たかを伝えてください。

開発者向け：ソースコードは GitHub の UNION025/DuneBox にあります。Intel と Apple Silicon の両対応版で、ビルドしたコミットと日時は data/BUILD.txt に書いてあります。作り方は scripts/build-mac-universal.sh を参照してください。
